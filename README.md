# 🚌 Bus Reservation System

A modern web-based Bus Reservation System that allows users to search for buses, check seat availability, select seats, enter passenger details, and complete the booking process through a simple and user-friendly interface.

The project is designed to simulate an online bus booking platform with user authentication, bus search, seat selection, passenger information, and payment workflow.

---

## 🚀 Features

### 🔐 User Authentication
- User Sign Up
- User Login
- Firebase Authentication
- Secure authentication flow

### 🚌 Bus Search
- Search buses based on:
  - Source
  - Destination
  - Travel date
- Display available buses and trip information

### 💺 Seat Selection
- Interactive seat selection interface
- View available and occupied seats
- Select preferred seats
- Support for sleeper-style bus seat layouts

### 👤 Passenger Details
- Enter passenger information
- Phone number validation
- Passenger details confirmation before payment

### 💳 Payment
- Dedicated payment page
- QR code based payment interface
- UPI payment option
- Copy UPI ID functionality
- Payment confirmation workflow

### 🎫 Ticket
- Booking confirmation
- Generate/display ticket details
- View passenger and journey information

### 📱 Responsive Interface
- Clean and modern UI
- User-friendly navigation
- Designed for desktop and mobile screens
